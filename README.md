# TabungKu – Ringkasan Tabungan

Aplikasi sederhana untuk mengelola ringkasan tabungan menggunakan Flutter.

## Fitur
- Melihat saldo dan target tabungan.
- Menambah saldo (Menabung).
- Mengurangi saldo (Tarik).
- Melihat riwayat transaksi.
- Melihat transaksi terakhir.

## Screenshot

Folder `tugas` berisi tangkapan layar aplikasi pada dua ukuran layar:

1. `phone.png` – Tampilan smartphone.
2. `tablet.png` – Tampilan tablet.

## Teknologi
- Flutter
- Dart

## Cara Menjalankan

```bash
flutter pub get
flutter run
```
